System Architecture & Multi-Agent Flow

              
LangGraph orchestration, state machines, and tools

            

          

          
        


        
        

          
          
          
          
        


        

          
          
          

            

              This system implements a production-grade 3-phase autonomous deep research workflow with 5 LangGraph nodes:
            


            

              

                
1. Scoping & User Clarification (`scoping.py`)

                
Evaluates user queries for ambiguity using structured Pydantic schemas (ClarifyWithUser), pauses execution if details are needed, and outputs a date-aware ResearchQuestion brief.

              


              

                
2. Supervisor Planning & Delegation (`supervisor.py`)

                
Decomposes briefs into distinct sub-topics and orchestrates parallel subagents concurrently using asyncio.gather with isolated context windows.

              


              

                
3. Parallel ReAct Sub-Researchers (`research_agent.py`)

                
Equipped with Tavily API and DuckDuckGo fallback tools, extracting web page excerpts and synthesizing structured ResearchNote objects.

              


              

                
4. Synthesis & Report Writing (`writer.py`)

                
Aggregates all research notes into an exhaustive Markdown report with Executive Summary, Body Sections, Key Takeaways, and formal Citations.

              

            

          


          
          

            

              LangGraph manages state persistence across immutable Pydantic schemas:
            

            

              
# LangGraph State Definitions

              
• ScopingState: user_query, user_response, clarification, research_brief

              
• SupervisorState: research_brief, delegated_tasks, completed_notes

              
• WorkerState: topic, search_queries, raw_results, notes

              
• ResearchReport: title, executive_summary, sources, full_markdown
